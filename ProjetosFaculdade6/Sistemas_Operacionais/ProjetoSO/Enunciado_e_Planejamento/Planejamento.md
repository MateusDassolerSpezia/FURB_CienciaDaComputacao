# Projeto de Sistemas Operacionais

## Enunciado do professor

Fonte: `Apresentacao_do_enunciado.md`, fornecido pelo professor.

## Proposta de implementação da equipe

### Ambiente

- Visual Studio Code (VS Code);
- HTML e CSS;
- Java.

### Ideia de implementação

- Criar **seis telas HTML**:
  - uma tela para o menu principal;
  - uma tela para cada um dos cinco módulos.
- Implementar cada módulo separadamente em Java.
- Na tela de menu, disponibilizar opções para:
  - escolher qual módulo executar;
  - sair do “Sistema Operacional”.
- Ao escolher um módulo, abrir sua respectiva tela e apresentar:
  - a execução do módulo;
  - o resultado da execução.

### Ideia de implementação futura

- Criar uma implementação que combine pelo menos dois módulos.
- Adicionar uma nova tela para demonstrar essa integração.
